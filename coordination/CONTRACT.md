# Pipeline contract
Rust backend, Flutter desktop-only frontend; offline calculations via a local JSON-lines process. No HTTP server. Parent owns engine, Flutter, integration. 16 lanes own calculation catalogs.

## Catalog schema
Each lane creates research/<lane>.json, a JSON array of EXACTLY 8 distinct calculations (128 total), and research/<lane>.md with cited research and worked derivations. Implementation promotes the researched definitions into backend/catalog/<lane>.json. Use closed-form numerical models, not fake simulation.
Each calculation object:
```json
{"id":"lane.unique_slug","title":"Human name","category":"Domain","level":"basic|intermediate|expert","description":"Purpose","formula":"Readable formula","assumptions":["Model limits"],"references":[{"title":"Source","url":"https://..."}],"inputs":[{"key":"r","label":"Resistance","unit":"ohm","default":1000.0,"min":0.0,"exclusive_min":true}],"outputs":[{"key":"i","label":"Current","unit":"A","expression":"v/r"}],"constraints":[{"left":"v","op":">=","right":"0","message":"Voltage must be nonnegative"}],"example":{"inputs":{"r":1000.0,"v":5.0},"expected":{"i":0.005},"relative_tolerance":0.000001}}
```
Input optional fields min,max,exclusive_min,exclusive_max; all values finite. Keys ASCII snake_case, unique; avoid reserved pi/e. Output expressions evaluated sequentially and can use earlier output keys. Operators + - * / ^ and functions sqrt, abs, exp, ln, log10, sin, cos, tan, asin, acos, atan, floor, ceil, min, max supported; pi/e constants. No conditionals, comparisons or arrays within expressions. Constraints left/right are expressions, op one of > >= < <= == !=. Guard division, square-root/log domains, geometry/model validity. Defaults and examples must pass. SI units except explicitly stated units (e.g. mil for empirical IPC). Expressions support scientific notation. Numeric expected values independently derived, not copied from the engine.
Numerical extension approved by integration: `expm1(x)` computes `exp(x)-1` accurately near zero via Rust `f64::exp_m1`. Use `-expm1(-x)` instead of cancellation-prone `1-exp(-x)` where small positive x is valid. Constraints are evaluated before outputs and may reference only input keys/constants.
Noise-budget extension: `log1p(x)` computes `ln(1+x)` accurately near zero via Rust `f64::ln_1p`. Stable algebra may use `expm1`/`log1p` without changing physical models or example oracles.
Transient conditioning primitives preserve the researched analytic models: `expm1mx_ratio(x)=(exp(x)-1-x)/x²`, with analytic limit 0.5 at zero; `step_overdamped_scaled(time,slow_rate,fast_rate,amplitude)` evaluates a dimensional two-real-pole step with `0<slow_rate<fast_rate`; `step_underdamped_scaled(natural_frequency*time,damping_ratio,amplitude)` evaluates a dimensional second-order step with `0<damping_ratio<1`. Convergent short-argument series factor dimensional amplitudes before tiny squared time products; no new physical approximations, time exclusions or seed outputs.
Shared conditioning also supports `hypot(a,b)` for root-sum-square without premature squaring, `exprel(x)=expm1(x)/x` and `log1prel(x)=log1p(x)/x` (both analytic limits 1 at zero), and `pf_tangent_difference(initial,target)` for the rationalized AC reactive-demand difference, including equal-factor zero.
`parallel_heat(power,branch_resistance,other_resistance)` evaluates the same positive-resistance parallel-path power split. A dominant branch uses `power/(1+branch/other)`; subnormal ratios in the weaker branch use square-root factors with power scaled before squaring, retaining representable dimensional heat without reciprocals overflowing or normalized ratios disappearing.

## Ownership and deduplication
IDs and physical problems must not duplicate lanes. Different rearrangements of one formula do not count as separate calculations. Each lane must include basic/intermediate/expert coverage. Read RESEARCH_BOARD.md before picking features, and other research files when boundaries overlap. Communicate overlaps on COMMUNICATION.md; parent resolves. Cite primary sources (manufacturers, standards, university material); explicitly label approximations. No claims of standards compliance from estimates.

## Git and communication
Integration branch: integration/electronics-calculators. Developers use feat/<lane> isolated worktrees; only own backend/catalog/<lane>.json, docs/features/<lane>.md. Testers use test/<lane> worktrees and own backend/tests/<lane>.rs. Reviewers read-only, save QA report in coordination/reviews/<lane>.md from root. Parent cherry-picks explicit commits after handoff, runs global checks after the wave, resolves findings. No force pushes or changes to another lane. No remote available; local branch pipeline only.
Shared Markdown bus: COMMUNICATION.md. Append concise addressed entries using read+edit; stale hash => reread+retry, never overwrite. Persistent lane reports linked on board. Agent messages may supplement, not replace bus. Every agent skips build/lint/tests/formatters mid-flight; parent runs once after each complete wave. Researchers do web research, no repository code exploration needed. Testers write independent behavioral tests and provide shell/JSON scenarios for parent to exercise. No tests that inspect source text or merely assert catalog counts. Reviewers assess numerical correctness, units, model limits and expression/input validation.
