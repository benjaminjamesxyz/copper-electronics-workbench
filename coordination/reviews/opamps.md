These are inspected manufacturer sources, not physical bench evidence or independent experimental replication. Research's unavailable Analog Devices sources were not promoted to inspected evidence.

## Findings

### OPA-1 — P2: preserve the permitted unity-follower identity
- ID: opamps.noninverting_stage.
- Anchor: backend/catalog/opamps.json:550–551 (v_out expression); corresponding guard expressions at 580–590 also require correction.
- Complete accepted input: r_ground=10000, r_feedback=0, v_in=1e-17, v_reference=1, v_out_min=-10, v_out_max=10, v_cm_min=-10, v_cm_max=10.
- Independent expectation: gain=1; v_out=1e-17. Rf=0 shorts the output to the inverting pin, so ideal feedback makes output equal Vin regardless of the reference branch.
- Static defect: v_reference+gain*(v_in-v_reference) first rounds 1e-17-1 to -1, then adds1 and returns zero. At v_in=1e-12 the same operation gives approximately 9.999778782798785e-13, relative error about2.21e-5 vs the declared1e-6 tolerance. The positive-resistance/range checks all allow the vector.
- Evidence vs inference: the topology is directly supported by inspected TI handbook pp.17–18 and SLOA011B section2; predicted current evaluator value follows from binary64 rounding and read expression evaluation, not an executed test. No real-device picovolt accuracy is claimed: the defect is loss within the explicitly ideal numerical model.
- Correction: universally equivalent v_in+(r_feedback/r_ground)*(v_in-v_reference), also used by input-only output-limit guards; no unity-case special branch or clamp.
- Parent verification: tiny signed Vin (±1e-17, ±1e-12) with Rf=0/reference1 must preserve the input at relative tolerance; retain nominal gain10 example, nonzero-reference amplification and swing rejections.
- Handoff: sent immediately to Main and later to TestOpamps. Bus append attempted but denied by tool transport.

### OPA-2 — P2: retain separate reference contribution in matched difference stage
- ID: opamps.difference_ratio_error.
- Anchor: backend/catalog/opamps.json:266–270 (v_out), with pin_voltage computation at260 and corresponding guards at297–308.
- Complete accepted input: r_one=r_two=r_three=r_four=10000, v_one=v_two=1, v_reference=1e-17, v_out_min=-10, v_out_max=10, v_cm_min=-10, v_cm_max=10.
- Independent expectation: differential_gain=1, common_mode_gain=0, pin_voltage=(1+1e-17)/2 (correctly rounds to0.5 as an absolute pin value), v_out=v_reference+(v_two-v_one)=1e-17. Matched ratios cancel external common-mode sources, not the reference.
- Static defect: numerator10000+1e-13 rounds to10000, making pin_voltage0.5; reconstructing output as2*pin_voltage-1 returns0. The entire reference contribution is discarded. Fixing common_mode_gain alone does not fix v_out or guard conditioning.
- Evidence vs inference: inspected TI handbook pp.24–25 establishes matched subtraction; generalized reference identity is independently proved by KCL. Present zero is a binary64 deduction from the expression, not an executed evaluator result.
- Correction: with q=R4/R3,k=R2/R1, evaluate (1+k)*q/(1+q)*(V2-V1)+(q-k)/(1+q)*V1+(1+k)/(1+q)*Vref, reusing stable common_mode_gain where permitted. Apply the same universally equivalent expression to input-only output guards. Retain the meaningful absolute pin_voltage output; do not clamp or special-case matching.
- Parent verification: matched equal-source vectors at ratios1 and10 with tiny signed reference (±1e-17 and±1e-12) must preserve the reference using relative tolerances; retain nominal mismatch example, both mismatch signs, pin-range and output-range rejection.
- Handoff: sent immediately to Main and later to TestOpamps. Report/bus persistence transport is unavailable in this reviewer session.

## Eight-model disposition and independent oracle reasoning
1. opamps.inverting_stage: formula/topology correct by KCL, gain=-Rf/Rin and reference-aware output. Pin domain correctly uses Vref, not source Vin. Positive resistor/order/swing guards present. Nominal independent current20uA through47kohm gives -0.94V/gain-4.7. Signed input and zero excitation allowed. No additional finding.
2. opamps.noninverting_stage: ideal KCL and gain1+Rf/Rg correct; pin domain uses Vin; Rf=0 explicitly valid. Nominal independent reference-branch current30uA and feedback drop2.7V yield3.1V/gain10. OPA-1 affects small output vs larger reference, including unity follower.
3. opamps.difference_ratio_error: Ad/Acm convention Vd=V2-V1 correct; ratio-first Acm preserves exact computed matching and avoids CMRR singularity. Pin common-mode, not source common-mode, is constrained. Nominal rational oracle k10,p101/111 yields Ad10+1/222,Acm1/111,pin1111/1110,out1121/1110; all expected outputs agree algebraically. OPA-2 affects output/reference conditioning despite correct Acm.
4. opamps.weighted_summing_stage: three input-resistor currents and gains are correctly independent; superposition about reference and Vref pin guard correct. Nominal currents20,-15,10uA sum15uA, gains-4,-2,-1, output-0.6V. Signed/zero sources allowed; positive resistors and output limits guarded. Floating output addition and constraint current-sum paths are algebraically equal but rounded differently; no additional reproducible actionable mismatch established.
5. opamps.integrator_constant_input: capacitor in feedback, slope=-(Vin-Vref)/(RC), known initial state, duration>=0 and both endpoints guarded. Nominal25uA charges100nF for2ms, slope-250V/s and final0.5V. Constant-slope endpoint sufficiency correct, zero duration/slope and signed ramp supported. Practical leakage/reset/DC-stabilization/slew caveats honest. Very extreme scalar overflow/underflow not exhaustively enumerated; no separate concrete defect beyond review scope proof established.
6. opamps.differentiator_ramp: input capacitor/feedback resistor topology correct; signed slope and Vref-Rf*C*slope output, T>0 guard, flat/descending ramps accepted, source voltage not falsely treated as pin common-mode. Nominal1000V/s injects10uA and produces-0.1V. Practical compensation and ramp-interior-only caveats agree with source, not an all-frequency realizability claim.
7. opamps.sinusoidal_slew_requirement: output peak (not RMS/p-p), frequencyHz and slopeV/s correctly use2*pi*f*Vpeak. Nonzero waveform domain deliberately excludes DC/zero amplitude; margin<1 correctly remains diagnostic. Both sine swing endpoints guarded. Nominal required400000*pi, design800000*pi, margin12.5/pi match all expected outputs. No standards/distortion guarantee or differential-rating substitution implied.
8. opamps.dominant_pole_gain_bandwidth: N=1+Rf/Rg correctly uses noise gain, not signed inverting signal gain; A0>1, GBW>0,Rg>0,Rf>=0 and minimum-stable-noise-gain guard correct. Exact within stated single-pole model: Gdc=A0/(1+A0/N), fcl=GBW/A0+GBW/N, gain deficit reciprocal; Gdc*fcl=GBW independently checks example. At N1,A0=2,GBW2Hz expect pole1Hz,Gdc2/3,fcl3Hz,approx2Hz,error1/3, exposing finite-loop distinction. Asymptotic GBW/exact unity crossing and low-loop diagnostic validity documented honestly. Real stability remains unverified and explicitly not certified.
